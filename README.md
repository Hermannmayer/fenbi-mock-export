# 粉笔模考 → 干净 A4 PDF

把粉笔（fenbi）行测模考解析页，转成一份**排版干净、可打印**的 PDF：
每题带上题干、四个选项、**我自己选的那一项（✓/✗ 标出）**、正确答案、全站正确率、我的用时、易错项、完整解析、考点；资料分析的统计图表原样保留。

解决的是这个痛点：直接在浏览器里 `Ctrl+P` 打印，页面上固定的顶栏、悬浮的「答题卡」按钮、浏览器页眉页脚会在**每一页**重复出现，最后得到一份 90 页的糊稿。

## 它长什么样

```
政治理论                                              20 题
┌───────────────────────────────────────────────┐
│ 01  单选题                                      │
│ 习近平总书记指出，发展新质生产力……下列表述正确的是（ ） │
│   A 全国各地开展数字化改造，说明人们可以……        │
│ ✓ B 依托原有基础叠加新技术实现迭代升级……（绿底=你选的+对的）│
│   C 传统产业数字化改造要抓住关键环节重点突破……     │
│   D 因地制宜开展数字化改造，说明矛盾的普遍性……     │
│                                               │
│  B 正确答案   32% 全站正确率   5秒 答题用时   C 易错项 │
│  ── 解析 ──────────────────────────────────    │
│  本题考查马克思主义。                             │
│  A项错误，联系是客观的……                        │
│  ...                                          │
│  考点  唯物辩证法                                │
└───────────────────────────────────────────────┘
```

- **✓ 绿底** = 你选了，而且选对了
- **✗ 红底** = 你选了，但选错了
- **✓ 无底色** = 正确答案，但你没选它

## 快速开始

1. **保存页面**：在粉笔解析页按 `Ctrl+S`，保存类型选「**网页，全部(\*.htm;\*.html)**」，存到**一个新建的空文件夹**里
   （会得到 `xxx.html` + `xxx_files\` 两样东西，必须放在同一层）
2. **拖上去**：把那个文件夹（或里面的 `.html`）拖到 `导出PDF.bat` 上
3. **拿成品**：同一文件夹里出现 `模考_题目+我的答案+完整解析.pdf`

命令行也行：

```bash
python fenbi_export.py "D:\模考\41季"                 # 输出到该文件夹
python fenbi_export.py "D:\模考\41季" -o out.pdf       # 指定输出路径
python fenbi_export.py "D:\模考\41季" --tsv            # 顺带导出作答对照表
python fenbi_export.py "D:\模考\41季" --no-pdf         # 只重排 HTML，不打印
```

详细步骤和排错见 **[TUTORIAL.md](TUTORIAL.md)**。

## 原理（三句话）

1. `Ctrl+S` 存下来的页面里，**130 道题的 DOM 已经全部渲染好了**——粉笔的解析页是一次性渲染的，不做懒加载分页。
2. 脚本用 CDP（Chrome DevTools Protocol）打开这个本地文件，把每道题的卡片 HTML、选中的选项、材料图表抓出来。
3. 抹掉站点自带的折叠逻辑（内联 `height:0; overflow:hidden`）、去掉工具图标和悬浮层，套上自己的 A4 打印样式，再交给无头浏览器打印。

**全程离线**：不访问粉笔、不登录、不调用任何在线服务。

## 隐私

- 脚本**不联网**，不上传任何内容；所有处理都在本机完成，中间文件写在系统临时目录、跑完自动删除。
- 本仓库**只包含代码和文档**，不含任何真实题目、答案、成绩单或截图。
- `.gitignore` 已屏蔽 `*.html`、`*_files/`、`mat_*.png`、`模考_*.pdf`、`作答对照.tsv` 等，避免误提交你的试卷。

---

## 已知限制

- 个别公式是图片，与正文行距略有错位。
- 材料图表按截图嵌入，单独成页时下方会留白。
- 只针对「解析页」结构；粉笔若改版，需要更新选择器（集中在 `JS_DUMP` / `JS_MAT` 两个常量里）。
